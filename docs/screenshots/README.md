# Screenshot guide

The SVG files in this folder are temporary placeholders displayed by the repository README.

Replace them with current application screenshots before a polished public launch. Recommended capture size is 1600 × 900 or larger with Windows display scaling at 100 percent.

Suggested captures:

1. `main-interface`: a populated story workspace showing the chapter outline, editor, and expanded right pane.
2. `themes`: a four-image collage showing Pen & Paper, Muted Sage, Midnight Ink, and Retro Terminal.
3. `ai-writing`: the AI writing window with connection names and manuscript text anonymized.
4. `memory`: the memory manager showing sample facts, plot threads, summaries, proposals, and warnings.

Do not capture API keys, provider account details, personal filenames, or private manuscript content. If PNG files are used instead of SVG, update the four image links in the root `README.md`.
